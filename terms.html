제1조 (목적)

이 약관은 파랑라온(이하 "회사")이 제공하는 비트코인 자동매매 소프트웨어 "라온3"의 이용권 구독 서비스(이하 "서비스")를 이용함에 있어 회사와 이용자의 권리·의무 및 책임사항을 정함을 목적으로 합니다.

제2조 (정의)

  1. "서비스"란 회사가 운영하는 서버에서 이용자가 등록한 거래소 API 키를 통해, 이용자 본인의 거래소 계좌에서 라온3 매매 규칙에 따라 주문을 자동 실행하는 소프트웨어 이용권 및 이에 부수하는 알림·지원을 말합니다.
  2. "이용자"란 이 약관에 동의하고 구독료를 결제하여 서비스를 이용하는 자를 말합니다.
  3. "거래소"란 이용자가 본인 명의로 가입·보유한 가상자산 거래소(OKX 등)를 말합니다.
  4. "API 키"란 이용자가 거래소에서 발급하여 회사에 제공하는 매매 권한 인증정보(API Key, Secret Key, Passphrase)를 말합니다.
  5. "사이클"이란 라온3 규칙에 따른 최초 진입부터 익절 또는 손절로 포지션이 종료될 때까지의 매매 단위를 말합니다.

제3조 (서비스의 성격)

  1. 서비스는 소프트웨어 이용권입니다. 회사는 투자 자문, 투자 일임, 자금 수탁, 수익 보장, 손실 보전을 하지 않습니다.
  2. 모든 매매는 이용자 본인의 거래소 계좌에서 실행되며, 자금은 서비스 이용 기간 내내 이용자 계좌에 남아 있습니다. 회사는 이용자의 자금을 보관·이체·출금할 수 없습니다.
  3. 매매 규칙(분할 진입, 추가 매수 간격, 익절·손절 기준, 레버리지 등)은 서비스 안내 페이지에 공개되어 있으며, 이용자는 이를 확인하고 이용을 결정합니다.
  4. 서비스는 이용자가 등록한 API 키의 권한 범위(매매) 안에서만 동작합니다. 회사는 출금 권한이 있는 API 키의 등록을 요구하지 않으며, 이용자는 출금 권한 없는 키만 제공하여야 합니다.

제4조 (이용계약의 성립)

  1. 이용계약은 이용자가 이 약관 및 위험 고지에 동의하고, 구독 플랜을 선택하여 결제를 완료한 때 성립합니다.
  2. 이용자는 서비스 개시를 위해 거래소 계정, API 키, 텔레그램 알림 연결 정보를 회사가 안내한 방법으로 제공하여야 하며, 제공이 지연되는 기간은 구독 기간에서 차감되지 않도록 회사가 개시일을 조정합니다.
  3. 회사는 이용자가 제공한 정보로 봇 인스턴스를 설정하고, 정상 연결이 확인된 시점부터 서비스를 개시하며 그 시점을 텔레그램으로 통지합니다.
  4. 만 19세 미만, 타인 명의 거래소 계정 사용, 허위 정보 제공의 경우 회사는 계약 체결을 거절하거나 해지할 수 있습니다.

제5조 (요금 및 결제)

  1. 구독료는 정액이며, 매매 성과에 따른 추가 수수료나 수익 분배는 없습니다.
  2. 결제 수단은 회사가 안내하는 방법(계좌이체, 카드 결제 링크 등)에 따릅니다. 거래소 매매 수수료·펀딩비 등 거래소에 지불하는 비용은 구독료에 포함되지 않으며 이용자가 부담합니다.
  3. 회사는 이용자의 거래소 가입 시 추천 코드가 적용된 경우 거래소로부터 추천 수수료를 받을 수 있으며, 이는 이용자의 거래 비용을 늘리지 않습니다.
  4. 요금 변경 시 회사는 최소 30일 전에 고지하며, 이미 결제된 기간에는 적용되지 않습니다.

제6조 (청약철회 및 환불)

  1. 이용자는 결제일로부터 7일 이내이고 서비스가 개시되기 전(봇 인스턴스 가동 전)이면 전액 환불받을 수 있습니다.
  2. 서비스가 개시된 후에는 「전자상거래 등에서의 소비자보호에 관한 법률」 제17조 제2항에 따라 청약철회가 제한될 수 있으며, 회사는 결제 전 이 사실을 고지하고 이용자의 동의를 받습니다.
  3. 서비스 개시 후 이용자가 해지를 원할 경우: 월 구독은 잔여 기간까지 이용 후 종료되며 환불되지 않습니다. 연 구독은 개시일로부터 30일 이내 해지 시 총액에서 월 구독료(39,000원) 및 결제 수수료를 공제한 금액을 환불하며, 30일 경과 후에는 환불되지 않습니다.
  4. 회사의 귀책(서버 장애 등)으로 연속 3일 이상 서비스가 제공되지 못한 경우, 그 기간만큼 이용 기간을 연장하거나 일할 계산하여 환불합니다.
  5. 매매 결과(손실)는 환불 사유가 되지 않습니다.

제7조 (해지 및 구독 만료)

  1. 이용자는 언제든 회사에 해지를 통지할 수 있습니다. 구독 만료일이 지나거나 해지된 경우 봇은 새 사이클을 시작하지 않으며, 진행 중인 사이클은 익절 또는 손절로 종료될 때까지 정상적으로 관리한 후 정지합니다. 회사는 진행 중인 포지션을 임의로 강제 청산하지 않습니다.
  2. 회사는 만료 3일 전부터 텔레그램으로 만료 예정을 안내합니다. 연장 결제가 확인되면 즉시 재개됩니다.
  3. 이용자가 API 키를 삭제·변경하거나 거래소 계정에 접근이 불가능하게 된 경우 서비스는 중단되며, 이는 이용자의 해지로 봅니다.
  4. 이용자가 제8조를 위반한 경우 회사는 사전 통지 후 계약을 해지할 수 있으며, 이 경우 환불되지 않습니다.

제8조 (이용자의 의무)

  1. 이용자는 서비스가 동작하는 거래소 계정(또는 서브계정)에서 직접 주문을 내거나 포지션을 조작하지 않습니다. 위반으로 인한 손실은 이용자의 책임입니다.
  2. 이용자는 자금을 추가·인출할 수 있으나, 포지션 보유 중 증거금 부족을 초래하는 인출로 발생한 손실은 이용자의 책임입니다.
  3. 이용자는 본인 명의의 거래소 계정과 API 키만 제공하며, 출금 권한이 없는 키를 제공합니다.
  4. 이용자는 거래소의 이용약관, 관련 법령 및 세무 신고 의무를 스스로 준수합니다.
  5. 이용자는 소프트웨어·서버·API를 무단 복제, 역설계, 재판매하지 않습니다.

제9조 (회사의 의무)

  1. 회사는 공개된 매매 규칙대로 소프트웨어가 동작하도록 합리적인 주의로 서버를 운영·감시합니다.
  2. 회사는 매매 발생 시 텔레그램으로 실시간 통지하고, 문의 채널을 통해 응대합니다.
  3. 회사는 이용자의 API 키를 암호화된 환경변수로만 보관하고, 서비스 종료 시 지체 없이 파기합니다.

제10조 (위험 고지)

  1. 가상자산 레버리지 거래는 원금 손실이 발생할 수 있습니다. 최대낙폭(백테스트 기준 −74.3%) 수준의 평가손실이 실제로 발생할 수 있습니다.
  2. 안내된 성과는 과거 데이터 기반 백테스트 및 운용자 실계좌 기록이며, 미래 수익을 보장하지 않습니다. 마이너스 연도가 존재합니다.
  3. 손절 규칙이 있으나 급격한 시장 변동, 거래소 장애, 네트워크 지연 시 예상보다 큰 손실이 발생할 수 있습니다.
  4. 서비스는 거래소 API에 의존하므로 거래소의 정책 변경, 점검, 장애로 매매가 지연·누락될 수 있습니다.

제11조 (책임의 한계)

  1. 회사는 매매 결과, 시장 변동, 거래소 장애, 이용자의 규칙 위반, 불가항력으로 인한 손실에 책임지지 않습니다.
  2. 회사가 책임을 지는 경우에도 그 범위는 이용자가 회사에 지급한 최근 12개월 구독료 총액을 한도로 합니다. 단, 회사의 고의 또는 중대한 과실로 인한 경우는 예외로 합니다.
  3. 회사는 이용자의 거래소 계정 보안(로그인 정보 유출 등)에 대해 책임지지 않습니다.

제12조 (API 키 및 정보 보호)

  1. 회사는 서비스 제공 목적으로만 API 키를 사용하며, 제3자에게 제공하지 않습니다.
  2. API 키는 접근이 제한된 서버 환경변수에 저장되며, 계약 종료·해지 시 7일 이내 삭제합니다. 이용자는 언제든 거래소에서 키를 삭제하여 접근을 차단할 수 있습니다.
  3. 기타 개인정보의 처리는 아래 개인정보처리방침에 따릅니다.

제13조 (서비스의 변경·중단)

  1. 회사는 매매 규칙, 지원 거래소, 서버 구성을 변경할 수 있으며, 이용자에게 불리한 변경은 30일 전 고지합니다. 이용자는 변경에 동의하지 않을 경우 해지할 수 있고, 이 경우 잔여 기간을 일할 환불합니다.
  2. 회사는 점검·장애 대응을 위해 서비스를 일시 중단할 수 있으며, 가능한 한 사전 고지합니다.
  3. 회사가 서비스를 영구 종료하는 경우 최소 30일 전 고지하고 잔여 기간을 일할 환불합니다.

제14조 (분쟁 해결 및 준거법)

  1. 이 약관은 대한민국 법률에 따라 해석됩니다.
  2. 서비스 이용과 관련한 분쟁은 상호 협의로 해결하며, 협의가 되지 않을 경우 한국소비자원 또는 회사 소재지를 관할하는 법원에 제기할 수 있습니다.
  3. 이 약관에 정하지 않은 사항은 전자상거래법, 약관규제법 등 관련 법령 및 상관례에 따릅니다.

3. 이용자의 권리

이용자는 언제든 개인정보 열람·정정·삭제·처리정지를 요청할 수 있으며, 회사는 지체 없이 조치합니다. API 키는 이용자가 거래소에서 직접 삭제하여 즉시 무효화할 수 있습니다.

4. 안전성 확보 조치

API 키는 암호화된 환경변수로만 저장하고 접근 권한을 대표자로 제한합니다. 출금 권한이 있는 키는 접수하지 않습니다. 계약 종료 시 서버 인스턴스와 함께 파기합니다.
