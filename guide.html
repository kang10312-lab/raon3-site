1

OKX 계정 만들기

봇은 OKX 거래소의 BTC 무기한 선물 시장에서 움직입니다. 계정은 본인 명의로 직접 만듭니다.

1-1. 반드시 이 링크로 가입하세요

이 링크로 가입해야 거래 수수료 할인이 적용됩니다.
다른 경로로 가입하면 할인이 적용되지 않고, 나중에 붙일 수도 없습니다.

OKX 가입하기 (수수료 할인 링크)

링크를 누르면 추천 코드가 자동으로 채워집니다. 가입 화면의 "추천 코드(Referral code)" 칸에 코드가 들어가 있는지 한 번만 확인하세요. 비어 있으면 추천 코드 36816702 를 직접 입력합니다.

  1. 이메일 또는 휴대폰으로 가입한 뒤, 앱의 안내에 따라 신원인증(KYC)을 완료합니다. 신분증과 얼굴 촬영이 필요합니다.
  2. 인증이 끝나면 준비 완료입니다. 새로 만든 계정은 그대로 봇 전용으로 쓰면 됩니다.

이미 OKX 계정이 있다면

봇 전용 서브계정을 하나 만드는 것을 권장합니다. 봇 자금과 다른 자산이 섞이지 않아 수익 확인이 깔끔하고, 봇이 다른 포지션과 충돌하지 않습니다.

  1. OKX 앱 → 프로필 → Sub-accounts → Create sub-account
  2. 이름은 자유롭게(예: raon3), 유형은 Standard
  3. 다음 단계부터는 이 서브계정을 기준으로 진행합니다
기존 계정에 추천 코드를 나중에 붙일 수는 없습니다수수료 할인은 신규 가입 시에만 적용됩니다. 할인을 받으려면 새 계정으로 가입하세요.
2

봇 전용 API 키 만들기 2-3 필독

API 키는 "이 계좌에서 매매만 해도 된다"는 허가증입니다. 출금 권한은 절대 주지 않습니다. 이 키로는 누구도 돈을 빼갈 수 없습니다.

2-1. 키 만들기 화면 열기

  1. OKX 앱 → 프로필(사람 아이콘) → API (또는 API management)
  2. Create API 누르기
  1. Account: 봇을 돌릴 계정 선택. 서브계정을 만들었다면 그 이름을 고릅니다. 비워두면 안 됩니다.
  2. API name: raon3bot
  3. Purpose: API trading (기본값 그대로)
  4. Permissions: Trade만 체크. Withdraw는 절대 체크하지 않습니다. (Read는 자동으로 켜져 있습니다)
  1. Markets: Perpetual만 체크
  2. Crypto: "+ Add" → BTC와 USDT 추가
  3. Trusted IP addresses: 끄기(OFF). 켜져 있으면 봇 서버가 접속하지 못합니다. 끌 때 경고가 뜨면 "I understand" 체크 후 Continue
  4. Passphrase: 직접 만듭니다. 8자 이상, 대문자·소문자·숫자·특수문자 각 1개 이상. 만든 즉시 메모장에 적어 두세요.

2-2. Submit → 얼굴인증

Submit을 누르면 얼굴인증이 시작됩니다. 밝은 곳에서 정면을 보고, 폰을 세로로 든 채 가만히 있으면 됩니다.

폴더블(접는) 폰은 접어서 바깥 화면으로펼친 화면은 가로 화면으로 인식되어 인증이 거부됩니다. 여러 번 실패하면 30분 잠기니, 처음부터 접은 상태로 하세요.

2-3. 키 저장 — 놓치면 처음부터 다시

Secret Key는 지금 이 화면에서 딱 한 번만 보입니다.
OK를 누르기 전에 3개를 먼저 저장하세요.

  1. "Created" 박스를 눌러 API Key와 Secret Key를 엽니다
  2. 각각 복사 버튼을 눌러 메모장에 붙여넣습니다
  3. 아래 3개가 모두 메모장에 있는지 확인한 뒤에야 OK를 누릅니다
API Key복사 → 메모장
Secret Key복사 → 메모장
Passphrase2-1에서 만든 것
화면을 닫으면 Secret Key는 다시 볼 수 없습니다놓치면 키를 삭제하고 얼굴인증부터 다시 해야 합니다. 30초만 천천히 하세요.

메모한 3개(API Key, Secret Key, Passphrase)와 어느 계정(메인/서브계정 이름)인지를 아래 방법으로 전달합니다.

3

텔레그램 알림 연결

진입·익절·물타기 등 모든 매매 내역이 텔레그램으로 실시간 도착합니다. 앱을 열지 않아도 무슨 일이 있었는지 알 수 있습니다.

  1. 텔레그램 앱을 설치하고 로그인합니다
  2. 검색창에 @raon3_alert_bot 을 입력해 "라온3 알림" 봇을 찾습니다 (또는 t.me/raon3_alert_bot)
  3. 시작(Start) 버튼을 누릅니다
  4. 텔레그램에서 @userinfobot 을 검색해 아무 말이나 보내면 Id: 숫자를 알려줍니다 → 그 숫자를 제출 폼의 "텔레그램 채팅 ID"에 적습니다
4

투자금 입금 (업비트 → OKX)

원화를 XRP로 바꿔 OKX로 보낸 뒤, OKX에서 USDT로 바꿉니다. XRP를 쓰는 이유는 전송이 몇 분이면 끝나고 수수료가 수백 원이기 때문입니다.

업비트의 24시간 규정을 먼저 알아 두세요 ① 원화를 입금하면 그 금액만큼 24시간 동안 코인 출금이 막힙니다.
② 처음 등록하는 출금 주소도 등록 후 24시간 뒤부터 출금됩니다.
그래서 순서는 원화 입금 → 주소 등록 → 하루 기다림 → XRP 매수 → 바로 출금입니다. XRP는 출금 직전에 사야 가격 변동에 노출되는 시간이 짧습니다.

4-1. OKX에서 내 XRP 입금 주소 확인

  1. OKX 앱 → Assets → Deposit → XRP 검색 → 네트워크 XRP Ledger
  2. 주소(Address)와 태그(Tag) 두 가지를 모두 복사합니다
  3. 서브계정을 쓰는 경우에도 입금은 메인 계정으로 받습니다 (4-4에서 옮깁니다)
태그를 빠뜨리면 돈이 사라집니다XRP는 주소와 태그가 한 세트입니다. 업비트 출금 화면의 "데스티네이션 태그" 칸에 반드시 입력하세요.

4-2. 업비트에서 XRP 사서 보내기

  1. 업비트 → 거래소 → XRP → 매수 → 시장가 → 보낼 금액 전부 매수
  2. 입출금 → XRP → 출금하기
  3. 출금방식 일반, 네트워크 XRP Ledger, 수량 최대
  4. 확인 → 주의사항 확인 → 입금처 OKX 선택
  5. 받는 주소에 OKX 주소, 데스티네이션 태그에 OKX 태그 입력
  6. 주소의 앞 4글자와 뒤 4글자를 눈으로 대조한 뒤 출금신청 → 2차 인증

큰 금액은 업비트가 자금 출처 확인을 요청할 수 있습니다. 은행 입금 내역 등 서류를 제출하면 보통 하루 안에 처리됩니다.

4-3. OKX 도착 → USDT로 바꾸기

  1. 5~10분 뒤 OKX 앱 → Assets에서 XRP 도착 확인
  2. 코인 목록에서 XRP → Convert
  3. From XRP → To USDT → Max → 변환

4-4. USDT를 거래(Trading) 지갑으로 옮기기

봇은 Trading 지갑의 USDT만 봅니다. Funding 지갑에 있으면 봇이 자금을 인식하지 못합니다.

메인 계정을 그대로 쓰는 경우

  1. Assets → Transfer → From Funding → To Trading
  2. Asset USDT → Max → Confirm

서브계정을 쓰는 경우 (두 번 옮깁니다)

  1. 메인 계정에서 Transfer → 상단 탭 Main and sub-account → 서브계정 선택 → From Main → To 서브계정 Funding → USDT → 금액 입력 → Confirm
  2. 프로필에서 서브계정으로 전환한 뒤 Transfer → From Funding → To Trading → Max → Confirm
여기까지 하면 준비 끝카카오톡 채널로 "입금 완료"라고 알려 주세요. 키와 채팅 ID를 받은 뒤 20분 안에 봇을 켜 드립니다.
5

가동 확인과 사용 규칙

봇이 켜지면 텔레그램에 시작 메시지가 오고, 5분 안에 첫 진입이 이루어집니다.

텔레그램에 오는 메시지

메시지뜻
봇 시작 … 거래소 선물잔고 $…봇이 계좌를 인식하고 가동을 시작했습니다
진입 분할1/7첫 매수. 전체 자금의 약 1/127만 사용합니다
TP 청산 … P/L $…익절. 한 사이클이 끝나고 잠시 후 새 사이클이 시작됩니다
진입 분할2/7, 3/7 …가격이 3% 내릴 때마다 추가 매수(물타기). 평균 단가가 낮아집니다
사이클 자금 재산정입출금이 있었으면 새 사이클부터 자동 반영됩니다

OKX 앱에서 직접 확인하기

Trade → Futures → BTCUSDT → 아래 Positions 탭. 봇의 포지션은 항상 Buy · Cross · 4x로 표시됩니다.

지켜야 할 세 가지

  1. 이 계정에서 손으로 주문하지 않습니다. 봇의 계산이 어긋나 예상치 못한 손실이 날 수 있습니다. 화면은 보기만 하세요.
  2. 돈을 더 넣거나 빼는 것은 자유입니다. Trading 지갑에 넣거나 빼면 다음 사이클부터 자동으로 반영됩니다. 단, 포지션이 열려 있을 때 큰 금액을 빼면 증거금이 부족해질 수 있으니 먼저 알려 주세요.
  3. API 키를 지우거나 바꾸면 봇이 멈춥니다. 바꿔야 할 때는 먼저 알려 주세요.

구독이 끝나면

만료일이 지나면 봇은 새 사이클을 시작하지 않습니다. 진행 중이던 사이클은 익절 또는 손절까지 정상적으로 마무리한 뒤 정지합니다. 만료 3일 전부터 텔레그램으로 안내가 갑니다. 연장하면 즉시 다시 시작됩니다.

시작 전 체크리스트

  • OKX 가입과 신원인증 완료
  • API 키 3종(Key · Secret · Passphrase) 저장 및 전달 — Withdraw 권한 없음, Trusted IP 꺼짐
  • 텔레그램 알림 봇 시작 후 채팅 ID 전달
  • USDT가 Trading 지갑에 들어 있음
  • 이 계정에서는 손으로 주문하지 않기로 함
